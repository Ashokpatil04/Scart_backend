# SwiftCart – E-Commerce Backend

SwiftCart Backend is a **Spring Boot REST API** that provides backend services for an e-commerce application, including product management and database operations.

## Features

*  Product management
*  Add products
*  Get product details
*  Update products
*  Delete products
*  REST API endpoints
*  Database integration

## Tech Stack

* **Java**
* **Spring Boot**
* **Spring Data JPA**
* **REST API**
* **MySQL**
* **Hibernate**
* **Maven**
* **Postman**

## Architecture

```text
Client / Frontend
       ↓
   REST API
       ↓
 Controller
       ↓
   Service
       ↓
 Repository
       ↓
    MySQL
```

## Run Locally

```bash
git clone https://github.com/Ashokpatil04/Scart_backend.git
cd Scart_backend
```

Open the project in **IntelliJ IDEA / Eclipse / VS Code**, configure your MySQL database in `application.properties`, and run the Spring Boot application.

The API can then be tested using **Postman**.

## Objective

To develop a scalable backend for an e-commerce application using **Spring Boot, REST APIs, JPA, and MySQL**.
